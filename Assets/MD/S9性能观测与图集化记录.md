# S9 性能观测与图集化记录

> 目标：把「物品图标走 Resources 单图加载」改成 SpriteAtlas 合批，并用 PerfHUD / Profiler 建立可复测的性能观测。
> 环境：Unity 2021.3.34f1c1，编辑器 Play Mode，默认 67 件存档。

---

## 一、实现

| 文件 | 改动 |
|---|---|
| `Assets/ArtRes/UI/ItemIcons/` | 10 张物品图标从 `Resources/ItemIcons` 移出（避免图集和 Resources 重复加载） |
| `Assets/Resources/ItemIconAtlas.spriteatlas` | 10 张图标合并成一张图集（运行时主对象为 `SpriteAtlas`） |
| `Assets/Scripts/UI/IconAtlasLoader.cs` | 加载图集、按 Sprite 名取图、带缓存 |
| `Assets/Lua/Bag/ItemCellCtrl.lua` | `LoadIcon` 优先走 `IconAtlasLoader`，失败回退 Resources |
| `Assets/GenConfig.cs` | 注册 `IconAtlasLoader`，重新生成 XLua Wrap |
| `Assets/Scripts/Perf/PerfHUD.cs` | FPS / 帧时间 / GC Alloc / DrawCall / Batches / SetPass / Triangles；F1 开关 |
| `Assets/Editor/Perf/PerfSetup.cs` | 图标图集化菜单；把 PerfHUD 加到 SampleScene |

### 踩坑：CreateAsset 不等于图集已打包

第一版用 `SpriteAtlasAsset.Save` 创建 `.spriteatlas`，编辑器里 `Resources.Load<SpriteAtlas>` 能拿到对象，
但 `atlas.spriteCount = 0`，`GetSprite` 全部返回 null，图标在游戏里直接消失。

最终做法：

```csharp
SpriteAtlas atlas = new SpriteAtlas();
SpriteAtlasExtensions.Add(atlas, packables);
AssetDatabase.CreateAsset(atlas, AtlasPath);
SpriteAtlasUtility.PackAtlases(new[] { atlas }, EditorUserBuildSettings.activeBuildTarget, false);
```

验证：`spriteCount = 10`，`GetSprite("63_31100063") != null`，图标正常显示。

## 二、实测数据（Item Tab，HUD 关闭）

| 指标 | 图集前（Resources 单图） | 图集后（SpriteAtlas） |
|---|---|---|
| Draw Calls | 31 | 31 |
| Batches | 31 | 31 |
| SetPass Calls | 18 | 18 |
| Triangles | 2524 | 2524 |

**结论：Item Tab 的总 DrawCall 没有下降，不能虚报。**

原因是这一页只显示 4 种图标纹理（截图可见蓝/绿/闪电/火四种），图标本身不是该页的瓶颈；
其余批次来自面板、按钮、TMP 文字和品质/选中图层。图集合并的是 10 张纹理，收益需要在
**装备页 / 宝石页**（图标种类更多）或独立包 + Frame Debugger 上复测。

> 注意：S7 记录的 27 events / 21 UGUI mesh 是「500 件顶部、图标为空」的快照，不能当图集优化前基线。

## 三、真实收益与截图

- 图标纹理：**10 张独立 PNG → 1 张图集**，同屏图标不再因纹理不同断批。
- `IconAtlasLoader` 缓存命中后，滚动重绑不再重复 `Resources.Load`。
- PerfHUD 提供可复现的 FPS / 帧时间 / GC / DrawCall / Batches 读数。

## 四、下一步

1. 在装备页/宝石页做同条件前后对比（或独立包 + Frame Debugger），确认图标批次数下降。
2. 把面板背景、按钮也合进 UI 图集，进一步减少断批。
3. PerfHUD 的 GC Alloc 计数器若在 2021.3 中无效，会显示 `n/a`，后续可以换 ProfilerRecorder 的 Memory 计数器。
