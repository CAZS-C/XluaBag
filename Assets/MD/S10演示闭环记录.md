# S10 演示闭环记录

> 目标：把「只会切三个 Tab 的背包界面」升级成可完整演示的背包 Demo。
> 环境：Unity 2021.3.34f1c1，PC，编辑器 Play Mode；2D 俯视表现，数据/背包/热更逻辑复用现有工程。

---

## 一、演示内容

### 操作

| 输入 | 行为 |
|---|---|
| `WASD` | 八向移动，支持左上/左下/右上/右下斜向；斜向归一化，边界 clamp |
| `F` | 靠近地面物品时拾取，显示 `F 拾取 XXX` |
| `B` / `ESC` / 关闭按钮 / 右下角“背包”按钮 | 打开或关闭背包 |
| 左键格子 | 选中 / 取消选中 |
| 右键格子 | 选中并弹出 `使用 / 丢弃 / 取消` |
| 菜单外点击 / `ESC` | 关闭右键菜单 |
| 帮助面板“重置演示” | 二次确认后清空 Demo 存档并重载 |

### 初始状态

- 背包 3 件 starter：铁剑、生命药水×3、红宝石×2。
- 地面 6 件：铁剑、火焰之剑、生命药水×3、传送卷轴、红宝石×2、神圣钻石。
- 玩家 HP 60/100，背包收起，房间一屏可见。

### 完整闭环

```
移动 → F 拾取 → AddItem → Toast → 存档
  → B 打开背包 → Tab / 滚动 / 左键选中
  → 右键菜单 → 使用（药水回血 / 装备 HUD）
  → 丢弃（扣 1 个，落到脚下，可再按 F 捡回）
  → 关闭背包继续移动
  → 退出重进保持；重置清档
```

## 二、实现结构

| 文件 | 职责 |
|---|---|
| `Assets/Scripts/Demo/DemoBootstrap.cs` | 等 Lua 初始化完成后生成世界、收起背包；处理 F 拾取、重置 |
| `DemoPlayerController.cs` | 八向移动（斜向归一化）、边界、朝向、输入锁 |
| `DemoPlayerStats.cs` | HP、治疗、装备 uid、HUD 同步 |
| `DemoWorld.cs` / `WorldItem.cs` | 初始/掉落物生成、最近物品、拾取、丢弃、存档 |
| `DemoHUD.cs` | 帮助、HP、装备、拾取提示、Toast、重置按钮、按钮反馈 |
| `BagPanelView.cs` | 背包显示/隐藏、关闭按钮、`B`/`ESC`、打开刷新 |
| `ItemCellRightClick.cs` | 右键转发，由 `BagItemPool` 运行时加到格子 |
| `ItemContextMenuView.cs` | 右键菜单显示/定位/回调 |
| `DemoArt.cs` | 运行时生成圆形/圆环/三角/网格占位 Sprite |
| `BagPanelCtrl.lua` | 右键选中、使用/丢弃规则、菜单/回调清理 |
| `ItemCellCtrl.lua` | 右键监听与缓存 |
| `Main.lua` | `DEMO_MODE` 分支：3 件 starter / 67 件测试数据 |

### 存档

| 场景 | PlayerPrefs key | 首次进入 |
|---|---|---|
| DemoScene | `PlayerData_Demo` | 3 件 starter + 6 件地面物品 |
| SampleScene | `PlayerData` | 67 件测试物品 |

`PlayerData` 新增：

- `hp`：HP 持久化；
- `equippedUid`：当前装备；
- `collectedWorldIds`：已拾取的初始地面物品；
- `droppedItems` / `nextGroundId`：玩家丢弃物（动态 id 从 1000 开始，避开初始 1~6）。

## 三、实测结果

### 1. 拾取与存档

- 空 Demo 存档进入：背包 3 件、地面 6 件、HP 60。
- 走到铁剑旁出现 `F 拾取 铁剑`；拾取后非空格子 4，`collectedWorldIds=1`。
- 停止再 Play：背包仍 4 件，地面不再刷新铁剑。

### 2. 使用药水

- HP 60 → 使用生命药水 → HP 90，数量 3 → 2。
- 停止再 Play：HP 90、数量 2 保持。

### 3. 装备与丢弃

- 右键铁剑，菜单按钮显示“装备”；使用后 HUD `武器：铁剑`，`equippedUid=1`。
- 右键丢弃铁剑：背包移除、HUD 恢复“武器：无”、地面生成 `worldId=1000` 的掉落物。
- 将掉落物冷却置 0 后按 F 可重新拾取，`droppedItems` 清空。

### 4. 重置演示

- 点击“重置演示”两次：清空 `PlayerData_Demo`，释放 LuaEnv，重新加载 DemoScene。
- 重载后：3 件 starter、6 件地面、HP 60、背包收起。

### 5. 回归

| 检查项 | 结果 |
|---|---|
| SampleScene | 67 件测试物品正常，普通存档 key 不受 Demo 影响 |
| 500 件虚拟滚动 | 28 个活动格子，Content 高度 23024，无报错 |
| 背包按钮 | SampleScene / DemoScene 均可开关背包 |
| 旧主角/技能按钮 | 已从 MainPanel 预制体移除，只剩 `btnBag` |
| 热更 v1→v2 | 复用未变化的 `lua`，下载 `PC` + `banner`，进入 DemoScene，状态 `current=2 pending=2 confirmed=2` |
| Windows Player | `Builds/Demo/XluaBag.exe` 构建成功，95.21 MB，0 errors |

> `PC` 是 BuildPipeline 生成的主 manifest 包，不包含 UI 预制体；`MainPanel` / DemoScene / C# Demo 层的改动需要重新出 Player 包，不能只靠 AB 热更。当前热更验证覆盖 Lua 与 banner。
>
> Player 构建回归时发现一个真实问题：v1→v2 只有 `PC`/`banner` 变化，如果只把变化包写进 `Res/2`，切换 `BundleRoot` 后 `lua` 包缺失。已修复为“未变化包从当前目录复制到新版本目录”，并在不带 `Assets/Lua` 的 Player 中验证 Lua 从 AB 正常加载。

### 6. 格子点击缩放修复

手动点击道具/宝石格子时，图标会变成约 3 倍大小；MCP 直接调用 `onClick` 不会触发。

根因：`BagItemCell.prefab` 根缩放为 `3.0769231`，对象池格子未激活时被 `DemoHUD.InstallButtonFeedback()` 加上 `UIButtonFeedback`，缓存了错误 `originalScale`；手动点击的 PointerDown/Up 恢复时把格子放大。

修复：

- `DemoHUD.InstallButtonFeedback()` 跳过所有挂有 `ItemCellRightClick` 的物品格子；
- `UIButtonFeedback.Awake()` 检测到 `ItemCellRightClick` 时直接禁用；
- `BagItemCell.prefab` 根缩放归一为 1。

验证：手动指针事件模拟下，格子 PointerDown/Up 前后均为 `1,1,1`；Tab/关闭按钮的缩放反馈仍正常。

## 五、已知限制

- 2D 俯视表现，玩家/地面/物品为运行时生成的占位图形，不包含角色动画。
- 不做角色面板、技能面板、Tooltip、拖拽、堆叠拆分、音效。
- 不处理平台/移动端触控；Android 仍只验证基础包拷贝逻辑。
- 右键菜单和 HUD 使用程序化 UI，视觉风格与现有背包面板保持近似但不是同一套美术。
