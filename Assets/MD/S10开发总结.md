# S10 背包演示开发总结

> 项目：XluaBag（Unity + XLua 背包系统）
> 范围：DemoScene 演示闭环、背包交互、热更修复、八向移动、回归与构建
> 日期：2026-11-24
> 当前远端：`master @ bec511d`

---

## 一、目标

把原来“只能切三个 Tab”的背包界面，扩展成可完整演示的背包 Demo：

```text
移动 → 拾取 → 入包 → 打开背包 → 选中 → 右键使用/丢弃 → 再拾取 → 存档
```

演示使用 2D 俯视占位场景，保留现有背包 UI、数据层、Lua 业务层和热更链路。

---

## 二、最终演示形态

### 操作

| 输入 | 行为 |
|---|---|
| `WASD` | 八向移动：上下左右 + 左上/左下/右上/右下；斜向速度归一化 |
| `F` | 靠近地面物品时拾取 |
| `B` / `ESC` / 关闭按钮 / 右下角“背包”按钮 | 打开或关闭背包 |
| 左键格子 | 选中 / 取消选中 |
| 右键格子 | 选中并弹出“使用 / 丢弃 / 取消” |
| 菜单外点击 / `ESC` | 关闭右键菜单 |
| “重置演示” | 二次确认后清空 Demo 存档并重载 |

### 初始状态

- 背包 3 件 starter：铁剑、生命药水×3、红宝石×2
- 地面 6 件：铁剑、火焰之剑、生命药水×3、传送卷轴、红宝石×2、神圣钻石
- 玩家 HP 60/100，背包收起，房间一屏可见

## 四、关键设计

### 1. 背包开关统一入口

`BagPanelView` 挂在 Main Camera 上，而不是 BagPanel 自己身上：

- BagPanel `SetActive(false)` 后，自身组件会停止 Update，无法再用 B 键打开；
- 放在常驻的 Main Camera 上，`B` / `ESC` / 关闭按钮 / 背包按钮都走同一个 `Show/Hide/Toggle`；
- 打开时隐藏背包按钮，避免底部露出半截；
- `onShown` 通知 Lua 刷新，`onHidden` 清理右键菜单。

### 2. 存档分离

| 场景 | PlayerPrefs key | 首次进入 |
|---|---|---|
| DemoScene | `PlayerData_Demo` | 3 件 starter + 6 件地面物品 |
| SampleScene | `PlayerData` | 67 件测试物品 |

`PlayerData` 新增：

- `hp`：HP 持久化
- `equippedUid`：当前装备
- `collectedWorldIds`：已拾取的固定地面物品
- `droppedItems` / `nextGroundId`：玩家丢弃物

掉落物 id 从 1000 开始，避开初始物品 1~6。

### 3. 拾取安全

`InventoryManager` 新增 `CanAdd(defId, count)`：

- 拾取前先完整预检查；
- `AddItem` 失败时不放入任何物品；
- 避免“部分放入后地面物品被销毁”的数据丢失。

### 4. 右键交互

- UGUI `Button.onClick` 只处理左键；
- `ItemCellRightClick` 实现 `IPointerClickHandler`，只处理右键；
- Lua 右键选中 uid，调用 `ItemContextMenuView.Show`；
- 使用/丢弃规则在 Lua，C# 只负责菜单显示、定位和按钮事件。

## 五、发现并修复的问题

### 1. 热更新新版本目录缺少未变化包

**现象**

Player 构建后，v1→v2 热更完成，但进入 DemoScene 时 Lua 报：

```text
module 'Config/ItemConfig' not found
```

**原因**

v1→v2 只有 `PC`/`banner` 变化，`lua` 未变化。旧逻辑只把变化的包写进 `Res/2`，切换 `BundleRoot` 后 `Res/2` 没有 `lua` 包。

编辑器里因为 `Assets/Lua` 本地文件优先加载，问题被掩盖；Player 中才暴露。

**修复**

`HotUpdateService` 在应用新版本时：

- 变化的包下载到 `Res/{新版}.tmp`；
- 未变化的包从当前基础包/上一版本目录复制过去；
- 保证新版本目录是完整包目录。

**验证**

Player 日志出现“复用未变化包：lua”，随后 Lua 从 AB 正常加载。

### 2. 手动点击物品格后图标放大

**现象**

手动点击道具/宝石格子后，图标、数量文字一起变成约 3 倍大小；MCP 直接调用 `onClick` 不会出现。

**原因**

- `BagItemCell.prefab` 根缩放为 `3.0769231`；
- `BagGridLayout.PositionCell()` 绑定时重置为 1；
- `DemoHUD.InstallButtonFeedback()` 给池子里的**未激活格子**也加了 `UIButtonFeedback`，缓存了错误 `originalScale = 3.0769`；
- 手动点击走 PointerDown/Up，恢复时把格子放大。

**修复**

- `DemoHUD.InstallButtonFeedback()` 跳过挂有 `ItemCellRightClick` 的物品格子；
- `UIButtonFeedback.Awake()` 检测到物品格子时直接禁用；
- `BagItemCell.prefab` 根缩放归一为 1。

**验证**

PointerDown/Up 前后格子缩放均为 `1,1,1`；Tab 等普通按钮仍保持 `1 → 0.94 → 1` 的反馈。
